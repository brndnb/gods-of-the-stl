# Gods of The STL

A free browser fighting game. The God of Everything (TGOE) created the planet **The STL** and 12 playable gods who fight on it.

**Play it:** https://brndnb.github.io/gods-of-the-stl/

## Controls
| Action | Key |
|---|---|
| Move / jump / crouch | A D W S or arrow keys |
| Front punch / back punch | J / I |
| Front kick / back kick | K / L |
| Block | O or Space |
| Throw | U |
| Ultimate (meter full) | R |
| Specials | ↓→, ←→, ↓←, ↓↓ + an attack button |
| Fatality (during FINISH THEM) | ↓ → ↓ + J, or F |
| Pause | Esc |

No install needed. Everything runs in the browser, and the music and sound are generated by the game itself.
